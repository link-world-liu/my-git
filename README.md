# 通讯录管理系统

一个用 C++ 编写的控制台通讯录管理系统，基于**结构体 + 数组**实现联系人的增删改查，适合作为 C++ 入门练习项目。

## 功能

| 序号 | 功能 | 说明 |
| :--: | :-- | :-- |
| 1 | 添加联系人 | 录入姓名、性别、年龄、联系电话、家庭住址 |
| 2 | 显示联系人 | 列出当前通讯录中的全部联系人 |
| 3 | 删除联系人 | 按姓名查找后删除，并将其后的记录依次前移 |
| 4 | 查找联系人 | 按姓名精确查找并显示详细信息 |
| 5 | 修改联系人 | 按姓名找到后重新录入该联系人的全部信息 |
| 6 | 清空联系人 | 二次确认后清空全部记录 |
| 0 | 退出通讯录 | 结束程序 |

## 技术要点

- **数据结构**：`Person` 结构体保存单个联系人；`Addressbooks` 结构体持有一个定长数组（`MAX = 1000`）和当前记录数 `m_Size`。
- **指针传参**：所有功能函数通过 `Addressbooks*` 接收通讯录，直接修改实参，避免大数组拷贝。
- **输入校验**：性别只接受 `1`（男）/ `2`（女），年龄限定在 `1 ~ 149`，非法输入会循环要求重新录入。
- **查找复用**：`isExist()` 返回联系人在数组中的下标（不存在返回 `-1`），供删除、查找、修改三处复用。
- **界面**：`showMenu()` 打印菜单，每项操作结束后 `system("pause")` + `system("cls")` 清屏刷新。

## 编译运行

### 方式一：Visual Studio

1. 用 Visual Studio 2022 打开 `通讯录管理系统.sln`。
2. 选择 `Debug | x64` 或 `Release | x64` 配置。
3. `Ctrl + F5` 编译并运行。

> 工程使用 `v143` 平台工具集（VS2022）与 Unicode 字符集，控制台应用（Console）。

### 方式二：命令行（MSVC）

```bat
cl /EHsc /std:c++14 /utf-8 通讯录管理系统1.cpp
通讯录管理系统1.exe
```

### 方式三：任意 C++ 编译器

源码仅依赖 `<iostream>` 与 `<string>`，用 g++ 亦可编译：

```bash
g++ -std=c++14 -finput-charset=UTF-8 -fexec-charset=GBK -o addressbook 通讯录管理系统1.cpp
```

> Windows 控制台默认使用 GBK（代码页 936），若输出中文为乱码，请先执行 `chcp 65001` 或将 `-fexec-charset` 设为 `GBK`。

## 已知限制

- 数据仅保存在内存中，**程序退出后记录丢失**（可扩展为文件读写持久化）。
- 通讯录容量固定为 1000 条，写满后拒绝继续添加。
- 姓名唯一：同名联系人会被 `isExist()` 匹配到第一条，无法区分。
